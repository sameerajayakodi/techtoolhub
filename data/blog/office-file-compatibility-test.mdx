## How I tested

- **The files:** one .docx, one .xlsx and one .pptx, each section labelled with a code (D1–D15, X1–X14, P1–P10) and a note saying what should appear. The Excel file lists the result Excel gives for every formula, so a wrong value is easy to spot.
- **The baseline:** I opened every file in Microsoft 365 for the web first. Anything that also looked wrong there was treated as a problem with the test file and left out.
- **The scoring:** Pass (same as the baseline), Partial (content there but something off, such as a substituted font or a chart that can't be edited) or Fail (missing, broken or a wrong value).
- **The round trip:** I saved each file from each suite and reopened the copy in Microsoft 365, because some suites open files well but change them on save.
- **The setup:** TODO (Windows version, PC, test date, exact app versions).

What the files don't cover: macros, pivot tables, dynamic-array formulas, animations and SmartArt. If you rely on those, test your own files before switching.
