# Affiliate programs for the tools in lib/affiliates.ts

Researched 2026-11-03 from the vendors' own pages where possible. Terms change often, so
check each official page before you join. Only paste a link into `lib/affiliates.ts` after
you are approved and have copied it from the program's dashboard.

## Programs you can apply to

| Tool                            | Program                                   | Where to apply                                 | Notes                                                                                                       |
| ------------------------------- | ----------------------------------------- | ---------------------------------------------- | ----------------------------------------------------------------------------------------------------------- |
| Proton (Mail, VPN, Pass, Drive) | Proton Partners Program (direct)          | https://proton.me/partners/affiliates          | Also listed on networks (CJ, FlexOffers, Involve Asia). Bans torrent/illegal-streaming sites.               |
| ONLYOFFICE                      | ONLYOFFICE affiliates, paid via Rewardful | https://www.onlyoffice.com/affiliates          | Main product to promote is DocSpace. Recurring commission on renewals. Questions: affiliates@onlyoffice.com |
| Evernote                        | Reportedly on PartnerStack                | Check evernote.com / evernote.partnerstack.com | Only third-party sources found; confirm on Evernote's own site first.                                       |

## Closed, referral-only or business-only

| Tool      | Status                                                                                                       |
| --------- | ------------------------------------------------------------------------------------------------------------ |
| Notion    | Official affiliates page (notion.com/affiliates) says it is not accepting new affiliates. Check again later. |
| Tuta      | No open affiliate program; the refer-a-friend scheme pays account credit, not cash.                          |
| DeepL     | Business partner program only (deepl.com/partners/contact-us), no individual affiliate program found.        |
| Nextcloud | Channel partner program for companies that sell or host Nextcloud; no affiliate program.                     |
| Obsidian  | Staff said on the forum they are not pursuing a referral or affiliate program.                               |

## No public affiliate program found

ChatGPT / OpenAI Codex, Claude / Claude Code, Gemini, Google Antigravity, Mistral, Cursor,
GitHub Copilot, Devin Desktop. Keep these as normal links (no `/go/` affiliate URL) unless a
vendor launches a program.
